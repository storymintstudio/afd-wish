## Air Force Day Flypast Wish

A lightweight, interactive Air Force Day greeting page built with vanilla HTML, CSS, and JavaScript.

Type a friend's name, watch a tricolour flypast animation, and generate a personalized Air Force Day wish.

## Features

🇮🇳 Tricolour flypast animation

Animated starry night background

Personalized greeting

Animated Indian Air Force anniversary counter

Responsive, mobile-friendly design

Native share / clipboard fallback

 Reduced-motion support

No frameworks or build tools required

Run

Simply open index.html in a browser.

## Tech

CSS3

Vanilla JavaScript
